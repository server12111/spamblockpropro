# feSpamBlock — сырой пул идей (1000)

Сгенерировано по результатам: полный разбор кода (11k строк, 9 модулей), ресёрч
(Telegram Business API, Bot API 9.x / Stars, helpdesk-практикии Intercom/Zendesk,
конкуренты TSB / Mava / Ticket Tool). Нумерация сквозная; топ-200 с приоритетами,
усилиями и привязкой к номерам отсюда — в IDEAS.md.
